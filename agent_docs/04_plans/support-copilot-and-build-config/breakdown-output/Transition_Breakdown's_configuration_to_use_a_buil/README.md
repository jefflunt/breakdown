# Transition Breakdown's configuration to use a build-style `agent_adapter` format (e.g. `copilot:anthropic/claude-haiku-4.5`), wire it into the LLM factory to correctly initialize CLI-based providers like Copilot and OpenCode, and completely deprecate and remove the legacy `llm` configuration block and API keys.

This task outlines a major configuration shift for the Breakdown project. It introduces a build-style `agent_adapter` string (e.g., `cli:provider/model`) to replace the verbose `llm` configuration. This involves writing a new parser for the config package, mapping the parsed outputs to internal provider/model representations in the LLM factory (specifically to support the Copilot CLI), and finally ripping out the legacy `llm` block and its API key fields from all structs and files.
