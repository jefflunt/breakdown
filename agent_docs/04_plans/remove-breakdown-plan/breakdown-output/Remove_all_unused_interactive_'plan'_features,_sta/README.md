# Remove all unused interactive 'plan' features, state saving logic, and legacy tree manipulation methods from the codebase (CLI, Prompts, LLM implementations, and Breakdown planner) to leave only the core non-interactive task decomposition logic.

This root task dictates the complete removal of unused interactive 'plan' features and legacy state management from the codebase. Currently, the tool is strictly a non-interactive task decomposer, making capabilities like interactive tree mutation, state saving, and related LLM prompts obsolete dead code.

The cleanup spans multiple layers of the application. It starts at the entry point by stripping unused CLI flags. It then moves into the prompt layer to delete obsolete files and their Go embed directives. From there, it requires modifying the core `LLMClient` interface and its providers to shed unused capabilities like `GeneratePlanName` and `GetExecCommand`. Finally, the domain models within the `pkg/breakdown` package must be cleansed of tree manipulation methods such as `EditNode`, `ReplanNode`, `AddChild`, and formatting logic. Completion of this initiative will result in a streamlined, run-once decomposition engine.
