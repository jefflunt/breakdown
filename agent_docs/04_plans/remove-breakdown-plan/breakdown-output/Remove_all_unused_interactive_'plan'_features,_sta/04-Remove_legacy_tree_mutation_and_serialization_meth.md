# Remove legacy tree mutation and serialization methods (`EditNode`, `ReplanNode`, `AddChild`, `AddSibling`, `InsertParent`, `DeleteNode`, `SerializePlan`, `GetExecCommand`, `FormatPlanStructure`) from `pkg/breakdown/breakdown.go` and `pkg/breakdown/node.go` to support the transition to non-interactive decomposition.

The interactive planning and state saving features are being removed from the codebase. As part of this, the `breakdown` package (specifically `breakdown.go` and `node.go`) contains several methods for mutating the plan tree (like editing, replanning, adding, or deleting nodes) and serializing the plan state. These methods (`EditNode`, `ReplanNode`, `AddChild`, `AddSibling`, `InsertParent`, `DeleteNode`, `SerializePlan`, `GetExecCommand`, `FormatPlanStructure`) are no longer needed as the application moves towards a non-interactive, stateless task decomposition logic. This task involves cleaning up these files by safely removing these methods and cleaning up any immediate internal references to them within these files.
